Running hold’em

This document extends on the “Robert’s Rules of Poker” (RRoP) and specifies generalized platform for multiple runs for every inactive pot at any stage of the game for any number of players.
Lately it became popular to give cash game players an option to agree on running heads-up all-in pot multiple times, thus reducing the variance of the outcome with only slight skew in odds. The pot is split into nnn as-similar parts, and every part is played as a separate game, and as such awarded to a run winner.
It may be of interest to generalize the rules in a way to allow for any inactive pot to be run multiple times, not only in a heads-up situation.

RRoP EXTENSION - Ties: Multiple odd smallest chips

  1. (e) In a button game, in the event of multiple odd smallest chips when three or more players chop the pot, the odd smallest chips are distributed one each in order to participating players beginning left (clockwise) of the dealer button. - “The Rules of Poker: Essentials for Every Game” by Lou Krieger & Sheree Bykofsky

Multiple runs

  1. In an all-in event at some stage of the game at least one inactive pot is being formed. The betting can continue in active side pot.
  2. After some inactive pot is formed, all pot stakeholders will be given an option to agree on running that pot multiple times.
  3. If all pot stakeholders agree on running the pot some explicit number of times bigger than 1, the pot will be annotated as such, and run multiple times after the main hand has been drawn, and after multiple runs have been dealt for earlier multi-run pots.
  4. Upon running the pot nnn times, pot will split into nnn as-similar parts called running pots, in order of decreasing size, with the largest difference between them being 1 smallest chip.
    EXAMPLE: If an inactive pot of 20 smallest chips is to be run 3 times, it will be split and ordered into 3 running pots of sizes 7, 7, 6 smallest chips.
  5. Depending on the stage of the game the pot was formed, remaining cards will be drawn remaining number of times in a way that the main hand cards are used for a stage of the game before the pot was formed, if existing previous running pots’ cards are reused for runs for later stages of the game, and only missing number of runs will be drawn in addition.
    EXAMPLE and ILLUSTRATION: -
  6. Every run is awarded to a run winner independently of other runs.
  7. In case of a tie running pot is split via usual RRoP tie rules, including our 5. (e) extension for multiple odd chips.

Comments

Running it multiple times has a few disadvantages which prevents it from being used in tournaments or being generally accepted tool by professional players:

  1. If two players collude on running it multiple times against each other, but not while some other player is active, they will play under a reduced risk and can afford on putting additional pressure on other players, e.g. via more frequent all-ins.
  2. Running it multiple times reduces a payout variance, so it reduces a risk and a probability (frequency) of bust events. It would thus reduce the number of buy-ins per hours resulting in a decreased cash flow compared to a normal game.
  3. Allowing it to run multiple times reduces a risk which makes a game easier from risk management point of view, thus not punishing novice risk management errors as much, thus reducing the principle at the heart of the game.
  4. Running it multiple times make players to spends more time on a game mechanics instead on playing poker.
  5. In a case of many multiple runs it can become overwhelming for the dealer to manage a table.
