Running hold’em

We extend on the “Robert’s Rules of Poker” (RRoP) and specify the rules for generalized multiple run variant of the game for any inactive pot at any stage of the game for any number of players.

Lately it became popular to give cash game players an option to agree on running heads-up all-in pot multiple times, thus reducing a payout variance with only slight skew of the winning odds, e.g. this epic rundown. The pot is split into nnn as-similar parts, every part is played separately, and as such awarded to the run winner independently of other runs.

It may be of interest to provide the generalized rules to allow for any inactive pot to be run multiple times, not only in a heads-up situation.

RRoP EXTENSION - Ties: Multiple odd smallest chips

  1. If two or more hands tie, an odd chip will be awarded as follows:
    (e) In a button game, in the event of multiple odd smallest chips when three or more players chop the pot, the odd smallest chips are distributed one each in order to participating players beginning left (clockwise) of the dealer button. – inspired by “The Rules of Poker: Essentials for Every Game” by Lou Krieger & Sheree Bykofsky

Multiple runs

  1. In an all-in event at some stage of the game at least one inactive pot is formed. The betting can continue in an active side pot.
  2. After some inactive pot is formed, all pot stakeholders are given an option to agree on running the pot multiple times.
  3. If all pot stakeholders agree on running the pot some explicit number of times larger than 1, the pot will be annotated as such, and run multiple times after the main hand has been drawn, and after multiple runs have been dealt for earlier multi-run pots.
  4. Upon running the pot nnn times, pot will split into nnn as-similar parts called running pots, in order of decreasing size, with the largest difference between them being 1 smallest chip.
    EXAMPLE: If an inactive pot of 20 smallest chips is to be run 3 times, it will be split and ordered into 3 running pots of sizes 7, 7, 6 smallest chips.
  5. Multiple runs are executed as follows: the main hand community cards are used for stages of the game before the pot was formed; also the main hand community cards are used for the first run for later stages after the pot was formed; if existing, previous running pots’ cards are reused for runs for later stages of the game; only extra missing number of the runs will in addition be drawn from the deck.
    EXAMPLE 1: Inactive pot is formed at flop, and is agreed to be run 3 times. After the main hand community cards has been drawn, we return to this inactive pot to execute the remaining runs. Same main hand flop community cards are used for all 3 runs. First of the 3 runs is decided based on the main hand turn & river and is immediately awarded to the winner, then 2 additional sets of turn & river are drawn from the deck to decide the remaining 2 runs.
    EXAMPLE 2: Inactive pot is formed at flop, and is agreed to be run 3 times. One older 2-runs pre-flop inactive pot was formed before this one. After the main hand has been drawn, we return to the older 2-runs inactive pot to execute its remaining run. After that older pot is resolved, we come to decide our flop inactive pot runs. Same main hand flop community cards are used for all 3 runs. One set of the main hand turn & river is used for the first run; one set of turn & river is reused from the second run of the older pot; just one additional set of turn & river has to be drawn to decide the third run of our pot.
  6. Every run is awarded to a run winner independently of other runs.
  7. In the case of a tie running pot is split via usual RRoP tie rules, including 5. (e) extension for multiple odd chips.

Comments

It could be of theoretical or practical interest to be aware of the following effects of running it multiple times:

  1. If two players collude on running it multiple times against each other, but not while some other player is active, they will play under reduced risk and can afford on putting additional pressure on other players, e.g. via more frequent all-ins.
  2. Running it multiple times reduces payout variance, so it reduces a probability (frequency) of bust events. Consequently expected number of buy-ins per hour is decreased, and so is a cash flow compared to a normal game.
  3. Allowing it to run multiple times reduces the risk which makes a game softer from risk management point of view, thus not punishing big risk management errors as much - some professional players prefer harder risk environment then to allow for weak players to get away with their errors.
  4. All bets are generally done on a basic assumption of a single run with corresponding risk effects, which are than different after stakeholders decide to run it multiple times. This doesn’t put any player in a disadvantage as all stakeholders have to agree to run it multiple times.
  5. Running it multiple times make players spend more time on a game mechanics instead on playing poker.
  6. If majority of players tend to run it multiple times, one player can be put into a position of social pressure by risking of giving an impression of being unfriendly if not conforming.
  7. In the case of many multiple runs it can become overwhelming for a dealer to manage the table.
